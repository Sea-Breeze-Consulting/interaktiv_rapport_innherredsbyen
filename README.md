# Interaktiv rapport – Innherredsbyen

Prototype som demonstrerer foreslått metode og analyseopplegg for oppdraget **«Treffsikre tiltak for grønne reiser i Innherredsbyen»**.

## Åpne prototypen

➡️ **[Åpne den interaktive rapporten](https://sea-breeze-consulting.github.io/interaktiv_rapport_innherredsbyen/)**

Prototypen åpnes direkte i nettleseren og krever ingen innlogging, installasjon, KI-tjeneste eller API-tilgang. Den er beregnet for Microsoft Edge, Google Chrome og andre moderne nettlesere.

## Om prototypen

Prototypen er et supplerende demonstrasjonsvedlegg til tilbudet. Den illustrerer hvordan datagrunnlag, analyser, barrierer og mulige tiltak kan presenteres og utforskes i oppdraget.

Det formelle og bindende tilbudsgrunnlaget fremgår av dokumentene som er levert i konkurransegjennomføringsverktøyet.

## Versjon

Publisert versjon er låst ved tilbudsfristen **25. september 2026 kl. 12.00**.
